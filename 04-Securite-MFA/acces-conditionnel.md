## 🔐 MFA - Conditional Access

### 🎯 Objectif
Forcer l’authentification multifacteur pour sécuriser Microsoft 365.

---

### 📌 Portée
- Utilisateurs
- Groupes

---

### ⚙️ Configuration

Dans :contentReference[oaicite:0]{index=0} :

- Security → Conditional Access  
- New policy  
- Users / Groups → sélectionner scope  
- Grant → Require MFA

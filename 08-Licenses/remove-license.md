## Retrait de licence

### Objectif
Supprimer acces aux services Microsoft

### Etapes
- 1. Users -> selectionner utilisateur
- 2. Licenses
- 3. Remove license

### Resultat
L'utilisateur perd acces :
- Email
- Teams
- SharePoint

### Cas reel
Employe quitte l'entreprise
les etapes : 
1.Block sign-in + reset password 
2.Sauvegarde données: Avant suppression ou retrait licence
.OneDrive → transférer fichiers
.SharePoint → vérifier accès
.Outlook → donner accès au manager ou créer délégation
3.Retirer licence
4.Retirer groupes
5.Supprimer user

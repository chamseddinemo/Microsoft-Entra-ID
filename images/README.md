## Images du repository

Mettre toutes les photos/GIF ici pour pouvoir les reutiliser partout dans le repository.

Structure recommandee :

- `images/users/`
- `images/groupes/`
- `images/roles/`
- `images/securite-mfa/`
- `images/licenses/`
- `images/applications/`
- `images/tickets/`

Exemple d'utilisation dans un fichier markdown :

`![Etape 1](../images/users/create-users-etape-1.gif)`

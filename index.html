🎯 Objectif

Ce projet simule un environnement entreprise en utilisant Microsoft Entra ID afin de développer des compétences en gestion des identités, sécurité et support technique IT.

🏢 Environnement

  • IT
  • RH
  • Finance
  • TR

Architecture

Users → Groups → Roles → Security (MFA)

Compétences couvertes

  • Gestion des utilisateurs
  • Gestion des groupes
  • Attribution des rôles
  • Sécurité (MFA, Conditional Access)
  • Troubleshooting help desk

Scénarios simulés

  • Login failure
  • MFA blocked
  • Account disabled
  • Access denied

🔐 Sécurité

MFA

  • Activation MFA
  • Test login

Conditional Access

  • Policy : Require MFA
  • Scope : Users / Groups

Scénarios

  • Reset MFA
  • User blocked

Scénarios

  • Login issue → Reset password
  • MFA issue → Reset MFA
  • Account disabled → Enable account
  • Access denied → Check group

Méthodologie

User → Password → MFA → Group → Role → Access
